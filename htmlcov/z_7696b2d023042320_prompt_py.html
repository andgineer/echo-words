16_PROMPT = """You are a vocabulary tutor. The word below is in {source_lang}. Analyse 

17this word or short phrase: {word} 

18 

19WRITE YOUR ENTIRE ANSWER IN {target_lang}. 

20This is absolute. Every part of the answer — the translations, the labels, 

21the register marks, the usage notes, the origin, the explanations of the 

22examples — is written in {target_lang}, and in no other language. These 

23instructions are in English; that says nothing about the answer language. 

24Do not answer in English unless {target_lang} IS English. Do not answer in 

25{source_lang} unless {target_lang} IS {source_lang}. Two things, and only 

26these two, stay in {source_lang}: the headword itself and the example 

27sentences (each of which is followed by its {target_lang} translation). 

28 

29{context_note}Be compact. No preamble, no closing remarks. {source_hints} 

30The order of the sections is fixed: 

31 

321. First line: the word being analysed, in bold. 

332. The translations, and nothing in front of them. Most frequent in 

34 everyday speech first. NEVER name the part of speech — not here, not 

35 anywhere in the answer. A register mark (colloquial, formal, slang, 

36 vulgar) goes AFTER the translation it belongs to, and only where it 

37 changes how the word is used. 

383. Forms — ONLY when this word actually changes shape in a way a learner 

39 has to recognise or produce. An adverb, a preposition, a particle, an 

40 invariable word and a fixed expression have none: for those, skip this 

41 section completely — no table, no heading, no remark about forms 

42 anywhere in the answer. When the word does change, give a table of at 

43 most six rows: first cell a short everyday phrase in {source_lang} 

44 using the form, second cell that phrase in {target_lang}. 

45 The phrases carry the grammar, so name no person, number, gender, case 

46 or tense — not inside the table, not on a line above or below it, not 

47 anywhere near it. No labels, no abbreviations, no gender note. Choose 

48 the forms that are irregular or that learners get wrong; leave out 

49 whatever follows the regular pattern. For a verb: the present forms 

50 whose stem changes, the past, and the participle. For a noun: the 

51 plural, and an article or ending that shows its gender. For an 

52 adjective: an irregular comparative. 

534. Usage: typical collocations and prepositions, what it is confused 

54 with; countability where it matters. 

555. Origin: if the word was borrowed, 1-3 sentences on which language it 

56 came from and how it travelled; for a native word, one line. 

576. Examples: 2-4 short everyday sentences, each followed by its translation. 

58 

59Give no phonetic transcription: pronunciation is delivered as audio. 

60 

61The input is either one lexical unit, or a single unit shown with the 

62words around it. Decide which before you answer. 

63- If the input is one lexical unit — an idiom, a collocation, a phrasal or 

64 separable verb, a fixed expression — analyse it WHOLE. Never take it 

65 apart, and never analyse one of its words on its own. 

66- Otherwise the input is a use of one unit, given with its context. 

67 Analyse THAT unit, in the sense it carries here, and treat the rest of 

68 the input as context only. 

69The unit you analyse is the headword of the first line and the value of 

70the word field. Everything else in the answer is about that unit. 

71Do not substitute a different word. If it looks 

72like a typo, do not silently fix it: 

73The test for one unit: its meaning does not follow from its words taken 

74separately, or it is simply the fixed way the language says this. When the 

75test passes, the whole input is the unit — a verb's object, a preposition 

76the verb governs, an article inside a set phrase are PART of it, never 

77context around it. When in doubt, keep the input whole: a unit carded whole 

78is at worst too specific, while a unit taken apart is wrong. 

79When the test fails, find the focus: the one word or unit a learner would 

80have stopped at. Prefer the word carrying the meaning over grammar words; 

81prefer a word with several senses over a transparent one; never pick a 

82proper name, a number, or a word spelled nearly as in {target_lang}. If the 

83focus is a verb bound to a reflexive particle, a separable prefix or a 

84governed preposition, it is that whole verb in its dictionary form, never 

85the bare stem. 

86Give the SMALLEST form a dictionary would list on its own. A word that only 

87modifies is never part of the unit and is dropped, however natural it sounds 

88attached: degree adverbs and intensifiers, quantifiers, adverbs of time, and 

89an auxiliary carrying no meaning of its own. "very tired" is not a unit and 

90"tired" is; keep the modifier only when dropping it changes the meaning, as 

91in a set phrase whose parts have stopped meaning what they say. add one short line beginning with ✏️ 

92and naming the likely intended spelling, and put that spelling in the 

93suggestion field of the card JSON. If there is no typo, suggestion is an 

94empty string. 

95If it is an idiom or a phrasal verb, explain both the literal and the 

96figurative sense and when it is used. 

97ALL EMPHASIS IS HTML. Use these tags and no others: <b> around the 

98headword, <i> around the {source_lang} example sentences and any 

99{source_lang} form quoted inside the text, and <table>, <tr> and <td> for 

100the forms section and nowhere else. No attributes on any tag. Emphasis 

101punctuation of any kind is forbidden — no markdown, no headings, no 

102bullet markers, no code fences. 

103The whole analysis: at most 3500 characters. 

104 

105After the analysis output the line ===CARD=== exactly, and immediately 

106after it one line of JSON, with no commentary and no HTML tags inside the 

107values: 

108{{"word": "...", "suggestion": "...", "candidates": ["...", "..."], 

109 "context_sense": 0, 

110 "meanings": [{{"label": "...", "translations": ["...", "..."], 

111 "examples": [{{"text": "...", "translation": "..."}}]}}]}} 

112word — the unit you analysed, in the form a dictionary lists it and the way 

113it would be typed into a search box: letters, spaces, hyphens and 

114apostrophes only, in the same script as the input. It is the whole input 

115when the input was itself one unit, and the unit you found inside it 

116otherwise. suggestion — the 

117likely intended spelling of a typo, or an empty string. 

118candidates — every unit of the input worth looking up on its own, most 

119useful first, at most three, each in the dictionary form the word field is 

120held to, and each able to stand as a headword alone. The first is always 

121identical to word. When the input was itself one unit, candidates holds 

122that one unit and nothing else. 

123Order them by what the learner most likely did not know and put that one 

124first. Never lead with the input restated. 

125 

126context_sense — ONLY when a context was given above: the index into meanings, 

127counting from zero, of the sense that context uses. Leave the field out 

128entirely when you were given no context. 

129 

130meanings normally holds one element with an empty label. Split it into 

131several (at most three) only when the senses are genuinely unrelated (like 

132bank "financial institution" and bank "river edge"); then label is a 

1331-3 word tag in {target_lang} telling the senses apart. 

134translations — the 2-4 main {target_lang} translations of that sense; 

135examples — the 1-2 shortest examples of that very sense: text is a 

136sentence in {source_lang}, translation is its rendering in {target_lang}. 

137In at least one example per sense, use the headword in exactly the form it 

138was given, unless that makes the sentence unnatural. 

139 

140Before you answer, check two things once more. Is every word of it in 

141{target_lang}, except the headword and the {source_lang} example sentences? 

142And is every emphasis an HTML tag, with no punctuation used for emphasis 

143anywhere? 

144"""

146_TEXT_PROMPT = """You are a language tutor. The text below is in {source_lang}. It is running 

147text — a sentence or a fragment of one — and not a dictionary entry: {word} 

148 

149WRITE YOUR ENTIRE ANSWER IN {target_lang}. 

150This is absolute. Every part of the answer — the translation, the notes, the 

151explanations — is written in {target_lang}, and in no other language. These 

152instructions are in English; that says nothing about the answer language. Do 

153not answer in English unless {target_lang} IS English. Do not answer in 

154{source_lang} unless {target_lang} IS {source_lang}. One thing only stays in 

155{source_lang}: the words and phrases you quote from the text itself. 

156 

157{source_hints}Be compact. No preamble, no closing remarks. 

158The order of the sections is fixed: 

159 

1601. A natural translation of the whole text into {target_lang}. One paragraph, 

161 reading as {target_lang} rather than as a gloss of the original. 

1622. What is hard here: 2-5 short notes, each on one thing a learner of 

163 {source_lang} would stumble over in this very text — a construction, the 

164 word order, a case or a mood, a set expression, a word that does not mean 

165 what it looks like. Say what the difficulty is, not what the word means. 

166 Leave out everything that is plain, and do not walk through the text word 

167 by word. 

168 

169Give no phonetic transcription. 

170ALL EMPHASIS IS HTML. Use exactly two tags and no others: <i> around anything 

171quoted from the text in {source_lang}, <b> around a term you are naming. 

172Emphasis punctuation of any kind is forbidden — no markdown, no headings, no 

173bullet markers, no tables, no code fences. 

174The whole answer: at most 3500 characters. 

175 

176After the answer output the line ===CARD=== exactly, and immediately after it 

177one line of JSON, with no commentary and no HTML tags inside the values: 

178{{"segments": [{{"label": "...", "surface": "...", "why": "..."}}]}} 

179 

180segments — the units of this text that are worth learning whole and looking up 

181on their own, at most five, the most useful first. A unit qualifies when its 

182meaning does not follow from its words taken one at a time, or when its parts 

183stand apart in the text so that neither part can be looked up alone: a verb 

184with a separable prefix, a verb bound to a reflexive particle, a verb bound to 

185a preposition or to a case, a set expression. A single ordinary word never 

186qualifies. 

187label — the unit's dictionary form in {source_lang}, written the way a 

188dictionary lists it and the way it would be typed into a search box: letters, 

189spaces, hyphens and apostrophes, nothing else, and in the same script as the 

190text you were given. 

191surface — the unit as it actually stands in this text, in {source_lang}; when 

192its parts stand apart, give them in the order they appear, joined by a space, 

193an ellipsis character and a space. 

194why — one short line in {target_lang} saying what makes the unit worth a look. 

195If the text you were given is itself one such unit and not a sentence, return 

196exactly one segment, whose label is that unit in its dictionary form. 

197If nothing in the text qualifies, return an empty list. 

198"""

200_CONTEXT_NOTE = """The word was met in this context: "{context}" 

201Give the senses this word has exactly as you would with no context in front 

202of you, and then name which of them this context uses. Lead the answer with 

203that sense — the translations, the usage and the examples open on it — and 

204let the other senses follow it. Never drop a sense because the context does 

205not use it, and never invent one to fit the context: when the word has only 

206the one sense, that single sense is the whole answer. If the sense used here 

207is rare, domain-specific or not recorded in dictionaries at all, say so 

208plainly and explain it rather than substituting the nearest dictionary 

209meaning. 

210 

211"""

213_EXTENDED_PROMPT = """You are a lexicographer. The word below is in {source_lang}. Analyse this 

214word or short phrase in depth: {word} 

215 

216WRITE YOUR ENTIRE ANSWER IN {target_lang}, and in no other language. These 

217instructions are in English; that says nothing about the answer language. 

218Only the headword and the example sentences stay in {source_lang}, and 

219every example is followed by its {target_lang} translation. 

220 

221{context_note}The reader has already seen the short entry, so do not skimp 

222on detail — but stay on the point in every section. 

223 

2241. First line: the word being analysed, in bold. 

2252. EVERY sense, not only the frequent ones: figurative, domain-specific, 

226 archaic, regional and slang alike. For each, the part of speech, the 

227 register mark, and the field it belongs to. If a sense lives only in a 

228 particular domain (law, medicine, sport, jargon), name that domain. 

2293. Origin, in depth: the source language, the original form and meaning, 

230 the route the word travelled, when it entered the language, related 

231 words within the language and cognates elsewhere. For a native word, 

232 the root and how it developed. Where the etymology is disputed, give 

233 the competing accounts. 

2344. Usage: set phrases, government, register, what it is confused with, 

235 false friends, the mistakes learners typically make. 

2365. Shades and near-synonyms: how it differs from them and which is apt 

237 where. 

2386. Examples: one or two per sense from section 2, each followed by its 

239 translation. 

240 

241For emphasis use ONLY the HTML tags <b> and <i>: the headword in bold, the 

242{source_lang} examples in italics. No markdown, no other tags. Give no 

243phonetic transcription. No JSON and no delimiters of any kind — this is 

244reading matter only. 

245"""

248def build_prompt(language: Language, word: str, target_lang: str, *, context: str = "") -> str: 

249 """Build the compact analysis prompt.""" 

250 context_note = _CONTEXT_NOTE.format(context=context) if context else "" 

251 return _PROMPT.format( 

252 source_lang=language.name, 

253 target_lang=target_lang, 

254 source_hints=language.prompt_hints or "", 

255 word=word, 

256 context_note=context_note, 

257 )

287def extract_card(raw: str, word: str, language: Language) -> ParsedCard | None: 

288 """Extract and validate the hidden card block, returning ``None`` when it is unusable.""" 

289 delimiter_at = raw.find(CARD_DELIMITER) 

290 if delimiter_at < 0: 

291 logger.warning( 

292 "no card block for %s/%r: the answer never wrote the delimiter", 

293 language.code, 

294 word, 

295 ) 

296 return None 

297 payload = raw[delimiter_at + len(CARD_DELIMITER) :] 

298 try: 

299 return parse_card_payload(payload, word, language) 

300 except CardParseError as exc: 

301 logger.warning( 

302 "unusable card block for %s/%r: %s; payload %s", 

303 language.code, 

304 word, 

305 exc, 

306 _logged(payload), 

307 ) 

308 return None

314 if delimiter_at < 0: 

315 logger.warning( 

316 "no segments block for %s: the answer never wrote the delimiter", 

317 language.code,

320 payload = raw[delimiter_at + len(CARD_DELIMITER) :] 

321 try: 

322 return parse_segments_payload(payload, language) 

323 except SegmentParseError as exc: 

324 logger.warning( 

325 "unusable segments block for %s: %s; payload %s", 

326 language.code, 

327 exc, 

328 _logged(payload), 

329 ) 

330 return None

333def _logged(payload: str) -> str: 

334 payload = payload.strip() 

335 if len(payload) <= PAYLOAD_LOG_LIMIT: 

336 return repr(payload) 

337 return f"{payload[:PAYLOAD_LOG_LIMIT]!r} … ({len(payload)} chars)"
