1"""The reference table of languages that can be studied, searched by the editor. 

2 

3The reader picks a language from here instead of naming one. Both fields they 

4would otherwise have typed are load-bearing and unfixable afterwards: the code 

5addresses Wikipedia, Wiktionary, the audio cache and the per-language word 

6tables, and the name is what the prompt calls the source language. Neither is a 

7free-text box. 

8 

9Only Latin- and Cyrillic-script languages are listed, because those are the 

10scripts the input validator can check (``languages._ALLOWED_SCRIPTS``); a 

11language whose writing it cannot read would refuse every word submitted to it. 

12 

13``name`` is the endonym, which is what reaches the prompt and labels the 

14language button. ``english`` names the Anki deck, following the decks already in 

15use. ``russian`` exists so the search answers the interface's other language. 

16""" 

17

24# What has been measured about the model's answers in a language. VOUCHED is the three 

25# the bench is built on; UNRELIABLE is where a fresh review read the answers and refused

32@dataclass(frozen=True) 

33class CatalogLanguage:

39 # dictionaryapi.dev's code, on the dozen languages it covers.

42 # the model listed under this code speaks another language (spec/decision-tts.md). 

43 piper_unusable: bool = False 

44 # The reader cannot tell a fluent invention from an answer, so the editor says what 

45 # is known about this language's answers instead of leaving the row to imply it. 

46 answers: str = UNMEASURED

48 @property

122BY_CODE: dict[str, CatalogLanguage] = {entry.code: entry for entry in CATALOG} 

123 

124 

125def catalog_language(code: str) -> CatalogLanguage | None: 

126 return BY_CODE.get(code) 

127 

128 

129# Every spelling a language answers to: its code, its endonym and both names the 

130# interface has for it. The target language is configured as one of these. 

131BY_NAME: dict[str, CatalogLanguage] = { 

132 spelling.casefold(): entry 

133 for entry in reversed(CATALOG) 

134 for spelling in (entry.code, entry.name, entry.english, entry.russian) 

135} 

136 

137 

138def catalog_language_named(name: str) -> CatalogLanguage | None: 

139 return BY_NAME.get(name.strip().casefold())
