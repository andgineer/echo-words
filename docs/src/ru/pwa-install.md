# Установка на телефон

Откройте HTTPS-адрес узла Tailscale в Safari, нажмите **Поделиться**, затем **На
экран «Домой»**. Установленное приложение открывается в отдельном окне, его
оболочка остаётся доступной офлайн, а запросы к API идут только по сети и
никогда не отдаются из кэша.

## Слова, отправленные без связи

Слово, отправленное, когда сервер недоступен, остаётся в локальной очереди FIFO
и повторяется при следующем открытии приложения или по событию браузера
`online`.

Каждая отправка несёт UUID, который сохраняется вместе с элементом очереди. Если
сервер принял POST, но ответ потерялся, повтор с тем же UUID вернёт исходную
запись, а не повторит работу LLM и синтеза речи. Эта карта квитанций, как и
история, живёт в памяти: она хранит не более 4096 принятых идентификаторов в
течение семи дней и сбрасывается при перезапуске бэкенда. Повтор за пределами
этого окна — уже новый запрос, но постоянная проверка дублей по паре
слово/колода в Anki всё равно не даст создать вторую карточку.

## Команда в меню «Поделиться»

Команда iOS позволяет отправить слово прямо из любого приложения, умеющего
делиться текстом.

1. Создайте команду, которая **принимает текст из меню «Поделиться»**, и
   сохраните вход команды в переменную `Phrase`.
2. Используйте **Match Text** с шаблоном

    ```
    \p{L}(?:[\p{L}\p{N}'’-]*[\p{L}\p{N}])?
    ```

    чтобы получить список слов. Как и собственный выбор слова в PWA, шаблон
    требует букву в начале и букву или цифру в конце, сохраняя апостроф или
    дефис внутри: `“don’t,”` превращается в `don’t`, а `'(go-over)'` — в
    `go-over`.

3. Если в списке больше одного элемента, используйте **Choose from List** и
   присвойте `Word` выбранное слово; иначе присвойте `Word` единственное слово
   напрямую.
4. Соберите словарь: `word` — это `Word`, `lang` — код настроенного языка,
   например `en`, а `lookup_only` — false. Только в ветке с несколькими словами
   дополнительно задайте `context` равным исходной `Phrase`.
5. Через **Get Contents of URL** отправьте этот словарь как JSON методом POST на
   `https://<node>.<tailnet>.ts.net/api/words`.
6. Добавьте команду в меню «Поделиться».

Tailscale должен быть подключён. Одно слово уходит сразу, а для текста
приложение спросит, какое слово разобрать, и сохранит всё выделение как
контекст — не открывая сервис наружу.
