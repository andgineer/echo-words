# Установка на телефон

Откройте HTTPS-адрес узла Tailscale в Safari, нажмите **Поделиться**, затем **На
экран «Домой»**. Установленное приложение открывается в отдельном окне, его
оболочка остаётся доступной офлайн, а запросы к API идут только по сети и
никогда не отдаются из кэша.

## Слова, отправленные без связи

Слово, отправленное, когда сервер недоступен, остаётся в локальной очереди FIFO
и повторяется при следующем открытии приложения или по событию браузера
`online`.

Каждая отправка несёт UUID, который сохраняется вместе с элементом очереди. Если
сервер принял POST, но ответ потерялся, повтор с тем же UUID вернёт исходную
запись, а не повторит работу LLM и синтеза речи. Эта карта квитанций, как и
история, живёт в памяти: она хранит не более 4096 принятых идентификаторов в
течение семи дней и сбрасывается при перезапуске бэкенда. Повтор за пределами
этого окна — уже новый запрос, но постоянная проверка дублей по паре
слово/колода в Anki всё равно не даст создать вторую карточку.

## Команда в меню «Поделиться»

Команда iOS позволяет отправить слово, выражение или целый отрывок прямо из
любого приложения, умеющего делиться текстом.

1. Создайте команду, которая **принимает текст из меню «Поделиться»**.
2. Соберите словарь: `word` — вход команды, `lang` — код настроенного языка,
   например `en`, а `lookup_only` — false.
3. Через **Get Contents of URL** отправьте этот словарь как JSON методом POST на
   `https://<node>.<tailnet>.ts.net/api/words`.
4. Добавьте команду в меню «Поделиться».

Tailscale должен быть подключён. Что именно пришло, решает бэкенд: слово или
выражение разбирается целиком и попадает в карточку, а текст возвращается с
переводом, разбором трудных мест и списком того, что стоит разобрать отдельно, —
и всё это не открывая сервис наружу.
