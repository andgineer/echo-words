# Ключи

echo-words берёт ключи из одного файла, `.deploy/.env` в вашей копии
репозитория, где бы ни работал его сервер. Создайте его из шаблона:

```bash
mkdir -p .deploy
cp .deploy.example/.env .deploy/.env
```

На Oracle Cloud каждое развёртывание копирует его на виртуалку, а на вашем
компьютере приложение читает его прямо на месте.

## Gemini: единственный обязательный ключ

```
GEMINI_API_KEY=...
```

Создайте его бесплатно в [Google AI Studio](https://aistudio.google.com/apikey).
Gemini — основная модель бесплатного пула, она делает большую часть работы: в
замерах, где были заполнены все ключи, она написала примерно четыре ответа из
пяти. Одного этого ключа приложению достаточно.

## Ещё бесплатные ключи: подстраховка, по желанию

```
GROQ_API_KEY=...
OPENROUTER_API_KEY=...
ZAI_API_KEY=...
```

Все бесплатные: [Groq](https://console.groq.com/keys),
[OpenRouter](https://openrouter.ai/keys), [Z.AI](https://z.ai/manage-apikey/apikey-list).
Каждый добавленный ключ приводит в пул новые модели. Они соревнуются с Gemini за
каждый ответ и подхватывают работу, когда Gemini медлит, исчерпал бесплатную
квоту или недоступен.

## OpenAI: по желанию, платный

```
OPENAI_API_KEY=...
```

Создайте его в [OpenAI](https://platform.openai.com/api-keys). Он оплачивает
две вещи: подробную статью, которую вы просите одним нажатием, и карточку, на
которую не смог ответить бесплатный пул. Без него подробная статья сообщает, что
недоступна, а карточка, на которой пул не справился, показывает ошибку.

Стоит это немного. Подробная статья обходится примерно в $0,036, так что на
доллар их выходит около 28. При собственном использовании автора, 17 подробных
статей за 30 дней, это около $0,60 в месяц. Карточка уходит к платной модели,
только когда бесплатный пул не смог на неё ответить. Кроме того, приложение
останавливается после 100 платных вызовов в день; это меняет
`ECHOWORDS_API_DAILY_CAP`. `ECHOWORDS_API_MODEL=` выключает платные вызовы
совсем, даже если ключ задан.

## Логин AnkiWeb

```
ECHOWORDS_ANKIWEB_USER=...
ECHOWORDS_ANKIWEB_PASSWORD=...
```

Серверу нужен ваш логин AnkiWeb, чтобы карточки попадали в ваши колоды; см.
[Настройку](configuration.md#ankiweb). `uv run inv dev` на своём компьютере не
синхронизируется с AnkiWeb, поэтому логин ему не нужен.

## Проверка

Экран **Состояние** в приложении показывает, каких ключей не хватает. Список
ключей бесплатного пула принадлежит llmbroker, библиотеке, которая и ведёт пул,
и эта команда печатает его для установленной версии с теми же ссылками на
регистрацию:

```bash
uv run python -m llmbroker env freetier
```
