# Попробовать на своём компьютере

Здесь echo-words запускается на вашем компьютере, чтобы посмотреть, что он умеет.
Пользоваться им так не задумано: он работает, только пока вы его держите
запущенным, открыть его может только браузер на этом компьютере, а карточки
остаются в пробной коллекции, которую не видит ни одно ваше приложение Anki. Для
настоящей работы [установите его на Oracle Cloud](deploy-oracle.md). Это тоже
ничего не стоит.

## Что понадобится

- [git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/getting-started/installation/)
- [Node.js](https://nodejs.org/) 22, потому что первый запуск собирает страницы
  приложения
- один бесплатный ключ LLM-провайдера: `GROQ_API_KEY`, `OPENROUTER_API_KEY`,
  `GEMINI_API_KEY` или `ZAI_API_KEY`. Где взять каждый, написано в
  [Настройке](configuration.md).

## Запуск

```bash
git clone https://github.com/andgineer/echo-words.git
cd echo-words
export GROQ_API_KEY=...            # или любой другой ключ бесплатного пула
export ECHOWORDS_ANKI_SYNC=false   # пробные карточки не попадут в ваш AnkiWeb
uv run inv dev
```

Откройте <http://127.0.0.1:8080>. Первый запуск собирает приложение и создаёт
`~/.echo-words/languages.toml` с английским, немецким и сербским; их можно
поменять в самом приложении.

Не убирайте `ECHOWORDS_ANKI_SYNC=false`. Без него для добавления карточки нужен
логин AnkiWeb, и пробные карточки тогда попадают в ваши настоящие колоды.

Всё, что сохраняет пробный запуск, лежит в `~/.echo-words`. Удалите эту папку,
чтобы стереть его. В установку на Oracle Cloud из неё ничего не переносится.
