{text}

{source_hints}

Begin with a natural translation of the complete text into {target_lang}. Then

After the article output ===CARD=== on its own line, followed immediately by one

{{"combinations": [{{"label": "<internal dictionary form>",
 "surface": "<forms as they stand in this text>",
 "why": "<short target-language reason>"}}]}}

combinations contains every unit of this text that clearly must be learned whole
and looked up as one item. A unit qualifies when its meaning does not follow from its
words one at a time, or when its lexical parts stand apart so that no part can be
looked up alone: for example a separable or reflexive verb, a governed
combination, a collocation or a set expression. A single ordinary word and an
arbitrary tense, negation or current argument do not qualify. Return the longest
real unit rather than overlapping smaller units. Do not return standalone words:
the backend adds every source word not claimed by a combination.

Return every unit that clearly qualifies, with no numerical limit. Do not pad the
list merely because the text contains several words. If uncertain whether a
group is one dictionary lookup target, omit it; an empty list is a correct and
useful answer.

label is an internal semantic check, never the text printed on the chip. Give the
clean dictionary form in {source_lang}, in the same script as the submitted text,
using only letters, spaces, internal hyphens and apostrophes. If you cannot name a
real dictionary lookup target for the whole combination, do not return it.

surface contains all and only the lexical parts exactly as they stand in the
submitted text. Copy them verbatim, in source order. When parts stand apart, join
them with " … ". Never translate, transliterate, correct or lemmatise surface.
For example: "Er steht ... auf" has label "aufstehen" and surface "steht … auf";
"Он ми се ... јавио" has label "јавити се" and surface "се … јавио", leaving
"ми" to the backend; "Ne bojim se" has label "bojati se" and surface "bojim se",
leaving "Ne" to the backend.

Do not return a standalone word, source index or context. The backend never
displays label. It validates surface, builds the visible chip from its exact
parts, adds every remaining source word as its own chip, and attaches the
submitted text as context.

Before writing JSON, compare the combinations with the constructions you named
in the article: every multi-word lexical unit discussed there must occur once in
combinations. Make sure their surfaces do not overlap. The JSON contains no card
fields because running text never creates a note.
